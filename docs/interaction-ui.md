## 1. 设计原则与视觉方向

1. **手机优先**：控制台按 390px 宽竖屏设计，单手拇指可达（核心按钮在下半屏）。
2. **大按钮、低频次**：主操作（锁屏/解锁/熄屏/唤醒）为 2×2 大按钮网格，触控目标 ≥ 64px 高。
3. **状态永远可见**：任何时刻控制台都能回答"电脑现在什么状态"（在线/离线、模式、亮灭屏、版本）。
4. **锁屏即屏保**：锁定窗口是"展示物"，视觉克制、信息层级少（时间 > 日期 > 无）。
5. **零外网依赖**：控制台与锁屏页面不使用任何 CDN 字体/图标/图片（系统字体栈 + 内联 SVG）。

### 配色与字体方向（设计 Token）

| Token | 值（建议） | 用途 |
| --- | --- | --- |
| `--bg-lock` | `#000000` ~ `#0A0E14` | 锁屏底色（黑屏模式纯 `#000`） |
| `--fg-lock` | `#F5F7FA`（非纯白，防刺眼） | 锁屏时间/日期文字 |
| `--accent` | `#3B82F6` | 控制台主操作（锁屏）、选中态 |
| `--success` | `#10B981` | 解锁、在线状态点 |
| `--warning` | `#F59E0B` | 熄屏、待确认 |
| `--danger` | `#EF4444` | 危险操作（重置 token、删除图片） |
| `--bg-console` / `--card-console` | `#121418` / `#1C1F26` | 控制台底色 / 卡片（深色为主，跟随 `prefers-color-scheme` 提供浅色） |
| 字体栈（锁屏） | `"Segoe UI", "SF Pro Display", "PingFang SC", "Microsoft YaHei", system-ui` | 时间用 Light 字重（300），数字 `font-variant-numeric: tabular-nums` 防跳动 |
| 字体栈（控制台） | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` | 常规 400/500 |

## 2. 桌面锁屏界面 UI

### 2.1 时钟模式（默认）

```
┌────────────────────────────────────────────────────────────┐
│                                                            │  ← 全屏置顶窗口
│                                                            │     底色 #0A0E14
│                                                            │
│                     ２１:４７                               │  ← [A] 时间：视口高度约 20%
│                                                            │     Light 字重，等宽数字
│                10月22日 星期四                               │  ← [B] 日期星期：时间字号约 1/4
│                                                            │     字重 400，透明度 75%
│                                                            │
│                                                            │
│                                                            │
│                                                            │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ [C] 提示条：按 Esc 输入密钥解锁 · Ctrl+Alt+Q 直接解锁  │  │  ← [C] 仅当鼠标移到顶部
│  └──────────────────────────────────────────────────────┘  │     64px 内时浮现，3 秒隐藏
└────────────────────────────────────────────────────────────┘
```

**元素与交互标注：**

- **[A] 时间**：`HH:mm`，24 小时制（设置可切 12 小时制）；垂直位置在屏幕黄金位（约上 1/3 与中点之间），水平居中；每秒刷新（不显示秒，但整分切换瞬间无跳变）。
- **[B] 日期星期**：跟随系统语言区域（如 `10月22日 星期四` / `Oct 22, Thu`）。
- **[C] 提示条**：默认隐藏。鼠标移动到屏幕顶部 64px 热区 → 淡入；3 秒无操作 → 淡出。点击提示条或按 `Esc` → 弹出 [D] 密钥输入浮层。防误操作：单纯移动鼠标/单击/普通按键**不触发任何退出**。
- **[D] 密钥输入浮层**（按 Esc 后出现）：

```
┌──────────────────────────────────────────────┐
│                                              │
│              输入本地解锁密钥                  │
│                                              │
│           ┌────────────────────┐             │
│           │  ● ● ● ●           │             │  ← 密码框，自动聚焦
│           └────────────────────┘             │
│                                              │
│           [ 取消 ]      [ 解锁 ]             │
│                                              │
│   （连续错误 5 次 → 冻结 30 秒并倒计时）        │
└──────────────────────────────────────────────┘
```

- 输入正确 → 立即关闭锁定窗口；错误 → 输入框抖动 + 清空；连续 5 次错误 → 浮层冻结 30 秒（按钮禁用 + 倒计时文案），期间不接受输入。
- 快捷键 `Ctrl+Alt+Q`（可在设置修改）→ 跳过密钥直接关闭锁定窗口（坐在电脑前的人的快速通道；密钥是给"知道密钥的家人/同事"用的）。

### 2.3 黑屏模式

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│                                                            │
│                                                            │
│                        （纯黑）                             │  ← 纯 #000000，无任何常驻内容
│                                                            │     鼠标移动不点亮、不显示内容
│                                                            │
│                                                            │
│                                                            │
│                                                            │
└────────────────────────────────────────────────────────────┘
   交互：按任意键或点击 → 短暂显示 [C] 提示条（同 2.1），随后回到纯黑；
         退出仍需密钥 / 快捷键，与时钟模式一致。
```

- 用途：夜间遮光、最大省电观感（显示器仍点亮但全黑；真正断电用"熄屏"）。
- 防误操作最强：日常移动鼠标完全无反馈，只有按键/点击才给出一次性提示。

### 2.4 布局与字号说明（实现参数）

| 项 | 规则 |
| --- | --- |
| 时间字号 | `clamp(64px, 20vh, 320px)`；4K/720p 均自适应 |
| 日期字号 | 时间字号的 25%，与时间间距 0.35em |
| 垂直位置 | 时间块整体位于 38% 高度处（视觉重心略高于几何中心） |
| 对齐 | 水平居中 |
| 多显示器 | 一期：主显示器显示内容、其余显示器纯黑置顶窗口（P1 提供策略设置） |
| 帧率 | 时钟整分刷新；秒级无动画（省电）；切换模式时 300ms 淡入淡出 |

## 3. 手机网页控制台 UI（响应式，390px 竖屏为主）

### 3.1 首次配对页（`/pair`）

```
┌────────────────────────────┐
│        remote-screen-lock   │
│       与你的电脑建立连接      │
│                            │
│  ┌──────────────────────┐  │
│  │ ① 扫码配对（推荐）     │  │  ← 默认展开
│  │ 用手机相机扫描电脑设置   │  │
│  │ 窗中的二维码即可        │  │
│  └──────────────────────┘  │
│                            │
│  ② 手动连接                 │
│  ┌──────────────────────┐  │
│  │ 电脑地址              │  │  ← http://192.168.1.244:8326
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │ 配对码（8位）          │  │  ← 4K7-QM2-ZP
│  └──────────────────────┘  │
│  ┌──────────────────────┐  │
│  │       连  接          │  │  ← 主按钮（≥64px 高）
│  └──────────────────────┘  │
│                            │
│  ⚠ 请确认手机与电脑连接同一   │
│    Wi-Fi / 局域网           │
└────────────────────────────┘
```

- 扫码进入时 URL 携带 token（`/pair#t=<token>`），页面静默校验（`POST /api/v1/pair/verify`）通过后直接跳主页，不打扰用户。
- 手动输码走 `POST /api/v1/pair`，成功返回 token 存 `localStorage`（键 `rsl.tokens`，支持多台电脑）。
- 失败反馈：配对码错误 → 输入框红框 + "配对码不正确（剩余 n 次）"；5 次后显示"5 分钟内禁止重试，剩余 mm:ss"。

## 4. HTTP API 设计草案

> 供 code 角色实现与联调；本节为草案（v1 冻结前可微调字段，路由与错误码原则不变）。

### 4.1 通用约定

- Base URL：`http://<被控端IP>:<端口>/api/v1`，默认端口 `8326`。
- 内容类型：`application/json; charset=utf-8`（图片上传除外，`multipart/form-data`）。
- 响应包络：

```json
// 成功
{ "code": 0, "msg": "ok", "data": { } }
// 失败
{ "code": 40102, "msg": "token 无效", "data": null }
```

- 所有时间戳为 Unix 秒（UTC）；所有接口幂等（重复下发同一指令返回当前状态，不报错）。

### 4.2 鉴权

| 方式 | 说明 |
| --- | --- |
| `Authorization: Bearer <token>` | 除 `GET /healthz`、`POST /api/v1/pair`、`POST /api/v1/pair/verify` 外全部必需 |
| 限速 | 鉴权失败：同 IP 10 次/分钟 → `429`；配对码错误：5 次 → 锁 5 分钟 |

### 4.3 路由总表

| 方法 | 路径 | 鉴权 | 说明 | 对应功能 |
| --- | --- | --- | --- | --- |
| GET | `/healthz` | 否 | 健康检查，仅返回版本 | 发现/诊断 |
| POST | `/api/v1/pair` | 否（配对码） | 配对码换 token | F-P0-04 |
| POST | `/api/v1/pair/verify` | 是（token） | 校验 token 有效性（扫码进入时静默校验） | F-P0-04 |
| GET | `/api/v1/status` | 是 | 状态总览 | F-P0-13 |
| POST | `/api/v1/lock` | 是 | 立即锁屏（含系统锁开关逻辑） | F-P0-06 |
| POST | `/api/v1/unlock` | 是 | 解除应用锁（关闭锁定窗口+亮屏） | F-P0-10 |
| POST | `/api/v1/screen/off` | 是 | 熄屏（保持主机不休眠） | F-P0-11 |
| POST | `/api/v1/screen/on` | 是 | 唤醒显示器 | F-P0-11 |
| GET | `/api/v1/mode` | 是 | 查询当前/默认屏保模式 | F-P0-07 |
| PUT | `/api/v1/mode` | 是 | 设置屏保模式（clock/image/black） | F-P0-07 |
| POST | `/api/v1/images` | 是 | 上传屏保图片（multipart，字段 `file`） | F-P0-12 |
| GET | `/api/v1/images` | 是 | 图片列表（含统计字段：尺寸/大小/使用中） | F-P0-12 |
| DELETE | `/api/v1/images/{id}` | 是 | 删除图片（删除使用中的图时自动回退 clock） | F-P0-12 / P1-03 |
| PUT | `/api/v1/brightness` | 是 | 亮度 0-100（P1；不支持返回 50302） | F-P1-02 |
| GET | `/api/v1/config` | 是 | 读取可远程下发的设置（时间制式/遮罩/默认模式） | F-P0-15 |
| PUT | `/api/v1/config` | 是 | 修改上述设置 | F-P0-15 |
| GET | `/api/v1/console`（页面） | 否 | 控制台单页应用（同 `/`、`/console`） | F-P0-03 |

### 4.5 错误码

| 错误码 | HTTP | 含义 | 控制台展示建议 |
| --- | --- | --- | --- |
| 0 | 200 | 成功 | — |
| 40001 | 400 | 参数缺失或格式错误（如 mode 非法） | "请求参数有误" |
| 40101 | 401 | 缺少 token | "未配对，请重新配对" → 跳 /pair |
| 40102 | 401 | token 无效（错误/已重置） | 同上，并清除本机 token |
| 40103 | 401 | 配对码错误 | "配对码不正确（剩余 n 次）" |
| 40901 | 409 | 状态冲突 | "当前状态不支持该操作" |
| 40902 | 409 | 无屏保图片却切 image 模式 | "请先上传图片" |
| 41301 | 413 | 图片超过 10MB / 总量超 50MB | "图片过大（上限 10MB）" |
| 41501 | 415 | 图片格式不支持 | "仅支持 jpg/png/webp" |
| 42901 | 429 | 尝试次数过多（限速/配对锁定） | 显示剩余等待时间 |
| 50001 | 500 | 被控端内部错误 | "电脑端出错了，请查看日志" |
| 50301 | 503 | 系统命令执行失败（熄屏/系统锁被拒） | "系统操作被拒绝，请检查系统设置" |
| 50302 | 503 | 设备不支持该操作（如亮度） | "当前显示器不支持软件调光" |

## 5. 交互流程图（文字版）

### 5.1 首次启动 → 设置 token → 手机接入

```
[电脑] 首次启动被控端
   │
   ▼
生成 token（持久化）+ 8 位配对码（10 分钟有效）+ 二维码
   │
   ▼
[设置窗·配对页] 展示二维码 / 配对码 / 局域网地址
   │
   ├─ 路径 A（扫码，推荐）
   │     手机相机扫描二维码
   │        │
   │        ▼
   │     打开 http://<ip>:8326/pair#t=<token>
   │        │
   │        ▼
   │     静默调 POST /pair/verify ──失败──► 展示"重新生成二维码"引导
   │        │ 成功
   │        ▼
   │     token 存 localStorage → 进入控制台主页
   │
   └─ 路径 B（手动输码）
         手机打开 http://<ip>:8326（可手动输入地址）
            │
            ▼
         输入 8 位配对码 → POST /api/v1/pair
            │
            ├─ 成功 ──► 返回 token → 存 localStorage → 进入控制台主页
            │
            └─ 失败 ──► 提示剩余次数（5 次）
                          │
                          ├─ 未超 5 次 ──► 重试
                          └─ 超 5 次 ──► 锁 5 分钟（显示倒计时）
                                            │
                                            └─ 仍失败 ──► 电脑端点"重新生成配对码"
```

### 5.2 远控锁屏 → 远控开屏（核心闭环）

```
[手机控制台] （每 3s 轮询 GET /status，状态卡实时刷新）
   │
   ├─ 点【立即锁屏】 ──► POST /api/v1/lock
   │        │
   │        ▼
   │   [电脑] 全屏置顶锁定窗口（按当前模式渲染）
   │          + 系统锁（若开关开启：LockWorkStation / CGSession）
   │        │
   │        ▼
   │   返回 { state: "locked" } → 状态卡更新为"已锁定"
   │
   ├─ 点【解锁】 ──► POST /api/v1/unlock
   │        │
   │        ▼
   │   [电脑] 关闭锁定窗口 + 点亮显示器
   │        ├─ 未开系统锁 ──► 直接回到桌面（state=active）
   │        └─ 已开系统锁 ──► 显示系统登录界面（本机输密码，安全边界）
   │
   ├─ 点【熄屏】 ──► POST /api/v1/screen/off
   │        ▼
   │   [电脑] 显示器关闭；主机保持运行（阻止休眠，HTTP 仍可达）
   │        ▼
   │   返回 { state: "screen_off", lockedMode: ... }（保留锁定态信息）
   │
   ├─ 点【唤醒】 ──► POST /api/v1/screen/on
   │        ▼
   │   [电脑] 显示器点亮，恢复熄屏前状态（locked 仍锁定 / active 回桌面）
   │
   └─ 点【模式切换】──► PUT /api/v1/mode ──► 锁定窗口即时重渲染（无需解锁）
```

### 5.3 被控端状态机（实现基准）

```
                lock (F-P0-06)
  ┌─────────┐ ─────────────────► ┌─────────┐
  │ active  │                    │ locked  │
  │ (正常)  │ ◄───────────────── │ (锁定)  │
  └─────────┘   unlock (F-P0-10) └────┬────┘
       │                              │ screen/off
       │ screen/off                   ▼
       │            wake     ┌────────────────┐
       └────────────────────►│  screen_off    │
                                │ (熄屏，保留   │
                                │  lockedMode)  │
                                └───────────────┘
   说明：
   · locked 三种子模式（clock/image/black）由 PUT /mode 即时切换，不改变状态机位置
   · screen_off 下 unlock = 唤醒 + 解除锁定 → active
   · 所有指令幂等：重复 lock 返回当前 locked 状态
```
