## 1. 产品定位

### 1.1 一句话定位

一款运行在 Windows / macOS 电脑上的开源锁屏与屏保工具：电脑上跑一个轻量"被控端"桌面程序，手机在同一局域网内扫码打开网页控制台（免装 App），即可远程**锁屏、解锁、熄屏、唤醒**，并可切换**时钟 / 自定义图片 / 黑屏**三种屏保模式。

### 1.2 背景与问题

| # | 痛点 | 场景 | 不解决的代价 |
| --- | --- | --- | --- |
| P1 | 离开工位忘记锁屏 | 泡咖啡/开会/回家，电脑还亮着且未锁 | 隐私泄露、合规风险（公司电脑） |
| P2 | 想远程关掉亮着的屏幕 | 躺下后发现电脑屏幕刺眼/费电 | 起身操作，体验割裂 |
| P3 | 想把闲置电脑当电子钟/相框 | 旧笔记本、客厅 PC 长期摆放 | 现有屏保不可远程控制、不够好看 |

市面上"远程控制"类工具（向日葵/ToDesk 等）重、需装两端 App、需注册账号；而"锁屏"这个高频小需求缺少一个**轻量、免账号、局域网直连、开源可自审**的方案。本产品填补这个空档。

### 1.3 目标用户

- **主力画像**：个人开发者 / 极客，家里有 1~3 台 Windows/macOS 电脑与一部安卓或 iPhone，重视隐私，愿意为"顺手"付出一次配置成本。
- **次要画像**：办公室职员（公司电脑需经常锁屏离开）；想把旧电脑改造为床头钟/电子相框的用户。
- **共同特征**：手机与电脑通常在同一局域网（家庭 Wi-Fi / 办公 Wi-Fi）。

### 1.4 价值主张

1. **手机免装 App**：浏览器扫码即用，安卓/iOS 天然全覆盖（来源：用户原始需求"要支持安卓、Win、macOS 多端"）。
2. **零账号、零云端**：纯局域网通信，无注册、无遥测，数据不出门。
3. **一个安装包**：GitHub 下载处只保留一个安装包，下载即用（来源：用户原始需求）。
4. **既是工具也是屏保**：锁屏界面本身做成"值得展示"的时钟/相框。

### 1.5 非目标（本期明确不做）

| 不做的事 | 原因 | 重新考虑条件 |
| --- | --- | --- |
| 公网远程控制（穿透/中转/FRP 集成） | 安全面与运维成本陡增，与"局域网直连"定位冲突 | 用户强烈诉求 + HTTPS 方案落地后 |
| 绕过操作系统登录密码的"解锁" | 系统安全边界，技术上不可行也不应做（见 8.1） | 永不 |
| 替换安卓手机的系统锁屏 | 系统限制：第三方应用无法替换安卓系统锁屏（见 8.2） | 永不（安卓端仅做遥控端） |
| 多用户/多电脑统一管理后台 | 单用户单机场景足够，避免范围蔓延 | 出现真实的多机管理诉求 |
| 云端图片/配置同步 | 与"零云端"冲突 | 用户主动要求且提供可选开关 |

## 2. 名词表

| 术语 | 标识 | 定义 |
| --- | --- | --- |
| 被控端 | Agent | 运行在被锁屏电脑上的 Tauri 2 桌面应用（Rust），含锁屏窗口渲染、系统控制与内置 HTTP 服务。 |
| 遥控端 / 控制台 | Console | 手机浏览器打开的网页控制台（PWA 形态），由被控端直接提供页面，局域网内访问。 |
| 控制 token | token | 32 位随机字符串，控制台调用被控端 API 的唯一凭证，HTTP Header `Authorization: Bearer <token>` 携带。 |
| 配对码 | pairing code | 首次配对时被控端展示的 8 位短码，手机手动输入后换取 token，10 分钟有效。 |
| 配对 | pairing | 手机首次获得 token 并通过校验的过程（扫码或输码）。 |
| 锁屏（应用锁） | lock | 被控端显示全屏置顶锁定窗口（时钟/图片/黑屏三种模式）。 |
| 系统锁 | system lock | 操作系统级锁：Windows `LockWorkStation`、macOS `CGSession -suspend`。开启后恢复使用必须在本机输入系统登录密码。 |
| 解锁 | unlock | 解除应用锁：关闭锁定窗口并点亮显示器。若系统锁已生效，解锁后显示的是系统登录界面。 |
| 熄屏 | screen off | 关闭显示器输出（Windows `SC_MONITORPOWER`、macOS `pmset displaysleepnow`），主机保持运行、HTTP 服务可达。 |
| 唤醒 | screen on / wake | 点亮显示器（不改变锁定状态）。 |
| 屏保模式 | mode | 锁定窗口的内容形态：`clock`（时钟）/ `image`（自定义图片）/ `black`（黑屏）。 |
| 本地解锁密钥 | local key | 在被控端电脑前退出锁定窗口所需的密钥（4~6 位），区别于系统登录密码。 |
| 轮询 | polling | 控制台每 3 秒请求一次 `GET /status` 刷新状态的机制。 |

## 3. 多端架构图

```
┌──────────────────────────── 被控端（Windows / macOS / Linux）────────────────────────────┐
│                                                                                          │
│   Tauri 2 桌面应用（Rust）                                                               │
│                                                                                          │
│   ┌──────────────────────┐        ┌───────────────────────────────────────┐               │
│   │ 锁定窗口层（全屏置顶） │        │ 核心控制层 core（纯 Rust）             │               │
│   │ · clock 时钟模式      │◄──────│ · 系统锁：LockWorkStation / CGSession  │               │
│   │ · image 图片模式      │ 渲染   │ · 电源：熄屏 / 唤醒 / 亮度             │               │
│   │ · black 黑屏模式      │指令    │ · 模式状态机（active/locked/screen_off)│               │
│   └──────────────────────┘        │ · 本地解锁密钥校验                     │               │
│                                   └──────────────┬────────────────────────┘               │
│   ┌──────────────────────┐        ┌──────────────▼────────────────────────┐               │
│   │ 设置窗 / 托盘         │        │ 内置 HTTP 服务（axum，默认 0.0.0.0:8326）│              │
│   │ · 二维码 + 配对码展示 │        │ · REST API /api/v1/*（Bearer token）   │               │
│   │ · 端口/模式/密钥设置  │        │ · 控制台静态页 / 与 /console（本地内置） │               │
│   └──────────────────────┘        └──────────────▲────────────────────────┘               │
│                                                  │                                       │
│                            配置持久化（config.toml，token/端口/模式/密钥哈希）              │
└──────────────────────────────────────────────────┼───────────────────────────────────────┘
                                                   │ 局域网 HTTP（同网段，明文，见 6.1 风险说明）
│                     ┌───────────────────────────┴───────────────────────────┐
│                     │          遥控端（手机浏览器 / PWA，免装 App）           │
│                     │  安卓 Chrome / iOS Safari / 任意现代浏览器             │
│                     │  · 首次：扫码或输配对码 → 保存 token（localStorage）     │
│                     │  · 常态：大按钮控制 + 每 3s 轮询 /status                │
│                     └─────────────────────────────────────────────────────┘
```

要点（对 code 角色的实现约束）：

1. 控制台页面**由被控端 axum 直接提供静态资源**，全部打包进应用，不依赖任何 CDN/外网。
2. 通信为**单向请求-响应**：手机 → 被控端；被控端不主动连接外部网络。实时推送（WebSocket/SSE）为 P2 演进项。
3. 一台手机可配对多台电脑（每台电脑一个独立 token，控制台内可切换/删除）；一台电脑默认只签发一个 token（多 token 管理 P1）。
4. 安卓端一期定位为"手机网页/PWA 控制台"，不提供被控端能力（系统限制说明见 8.2）；Tauri 2 Android APK 为二期可选项（P2）。

## 4. 核心用户故事

> 验收标准供 code 角色与验收人逐条核对；所有"≤ x 秒"均指局域网内正常网络条件。

**US-01 首次配对**
作为电脑主人，我首次打开被控端后，希望拿到二维码和配对码，以便手机扫码即可开始使用控制台。
- [ ] Given 被控端首次启动且尚无 token，When 打开设置窗，Then 显示包含 `http://<局域网IP>:<端口>/pair#t=<token>` 的二维码、8 位配对码与"重新生成"按钮。
- [ ] Given 手机与电脑在同一局域网，When 用手机相机扫描二维码，Then 浏览器打开配对页、自动保存 token 并直接进入控制台主页。
- [ ] Given 手机无法扫码，When 在配对页手动输入 8 位配对码并提交，Then 校验成功后返回 token、进入控制台主页。
- [ ] Given 配对码连续输错 5 次，When 再次提交，Then 请求被拒绝并提示"5 分钟内禁止重试"且显示剩余等待时间。

**US-02 远程锁屏**
作为离开工位的用户，我希望在手机上点一下就能锁屏，以便保护电脑隐私。
- [ ] Given 被控端处于 active 状态且控制台在线，When 点击"立即锁屏"，Then ≤1 秒内被控端进入锁定窗口（按当前模式渲染）并置顶全屏。
- [ ] Given 系统锁开关开启（默认开启），When 远程锁屏执行，Then 同时调用系统级锁（Windows LockWorkStation / macOS CGSession）。
- [ ] Given 手机在指令下发后立即断网，When 被控端已收到指令，Then 锁定状态保持，不因遥控端断开而回退。

**US-03 远程解锁（应用锁）**
作为回到电脑前的用户，我希望在手机上点"解锁"就退出屏保锁屏，以便不用碰键盘鼠标。
- [ ] Given 被控端处于 locked 状态，When 点击"解锁"，Then ≤1 秒内锁定窗口关闭且显示器点亮。
- [ ] Given 系统锁已生效，When 点击"解锁"，Then 关闭应用锁定窗口后显示系统登录界面（需本机输入密码），且控制台提前以文案说明该边界。
- [ ] Given 被控端处于 active 状态，When 点击"解锁"，Then 接口幂等返回成功，状态不变，不报错。

**US-04 熄屏与唤醒**
作为躺在床上不想起身的人，我希望远程熄屏/唤醒显示器，以便灭灯睡觉和第二天点亮。
- [ ] Given 屏幕点亮，When 点击"熄屏"，Then ≤1 秒内显示器关闭，且熄屏期间控制台轮询仍能正常返回状态（HTTP 服务可达、主机不休眠）。
- [ ] Given 屏幕熄灭，When 点击"唤醒"，Then ≤1 秒内显示器点亮，并恢复熄屏前的锁定状态（locked 则仍锁定，active 则回到桌面）。
- [ ] Given 被控端处于 locked 状态，When 点击"熄屏"，Then 进入"锁定+熄屏"组合状态，唤醒后仍显示锁定窗口。

**US-05 切换屏保模式**
作为用户，我希望在时钟、自定义图片、黑屏三种屏保模式间远程切换，以便不同场景使用（展示/相框/纯遮光）。
- [ ] Given 控制台在线，When 点击模式切换（clock/image/black），Then ≤1 秒内锁定窗口按新模式渲染；若当前未锁定则仅记录默认模式。
- [ ] Given 当前为黑屏模式且已锁定，When 切换为时钟模式，Then 无需解锁即直接切换。

**US-06 设置自定义屏保图片**
作为想把电脑当相框的用户，我希望从手机上传一张图片作为屏保，以便展示家人照片或作品。
- [ ] Given 控制台在线，When 上传 jpg/png/webp 图片（≤10MB），Then 上传成功、出现在图片列表并标记"使用中"，锁定窗口以 cover 方式铺满显示。
- [ ] Given 上传超出大小限制或非支持格式，When 提交，Then 返回明确错误提示（错误码见 interaction-ui.md 4.5），页面展示可读原因。
- [ ] Given 图片列表为空，When 切换到 image 模式，Then 拒绝切换并提示"请先上传图片"（状态保持原模式）。

**US-07 亮度调节（P1）**
作为床头钟用户，我希望在手机上调节屏幕亮度，以便夜间不刺眼。
- [ ] Given 系统支持亮度调节，When 拖动亮度滑杆（0-100），Then ≤1 秒内屏幕亮度随之变化，滑杆松手后停止下发。
- [ ] Given 外接显示器不支持软件调光，When 拖动滑杆，Then 返回 not_supported，页面提示"当前显示器不支持软件调光"。

**US-08 查看被控端状态**
作为用户，我希望控制台实时看到电脑的在线状态、当前模式和版本，以便确认指令是否生效。
- [ ] Given 被控端在线，When 控制台每 3 秒轮询，Then 状态卡展示：在线（绿点）、主机名、系统、当前模式、屏幕状态（亮/灭）、应用版本、本机时间。
- [ ] Given 被控端离线（关机/断网/服务停止），When 轮询连续 2 次失败，Then 状态卡变灰显示"离线"，所有控制按钮禁用并提示"被控端不在线"，恢复后 10 秒内自动恢复可用。

**US-09 本地退出锁屏（防误操作）**
作为坐在电脑前的用户，我希望输入密钥或按快捷键即可退出锁定窗口，且日常键鼠操作不会误触发退出。
- [ ] Given 锁定窗口显示中，When 鼠标移动到屏幕顶部 64px 区域，Then 顶部浮现提示条"按 Esc 输入密钥解锁（Ctrl+Alt+Q 直接解锁）"，3 秒无操作后自动隐藏。
- [ ] Given 锁定窗口显示中，When 单击/移动鼠标/敲普通按键，Then 不退出锁定（防误操作）。
- [ ] Given 密钥输入浮层，When 输入正确密钥，Then 锁定窗口立即关闭；When 连续输错 5 次，Then 冻结输入 30 秒并倒计时提示。
- [ ] Given 快捷键默认 Ctrl+Alt+Q，When 在锁定窗口按下，Then 直接关闭锁定窗口（快捷键可在设置中修改）。

**US-10 token 重置**
作为担心 token 泄露的用户，我希望一键重置 token，以便让旧手机立即失效。
- [ ] Given 设置窗已打开，When 点击"重置 token"，Then 弹出二次确认（说明所有已配对手机将失效），确认后旧 token 立即失效（旧 token 请求返回 401），并展示新的二维码/配对码。
- [ ] Given token 已重置，When 旧手机的控制台轮询，Then 收到 401 并进入"重新配对"引导页。

## 5. 功能清单

优先级定义：P0 = 一期（M1，Windows）必须交付；P1 = 一期后尽快（M2）；P2 = 远期（M3+）。每条含验收标准。

### 5.1 P0（一期必须）

| 编号 | 功能 | 说明 | 验收标准 |
| --- | --- | --- | --- |
| F-P0-01 | 被控端应用骨架 | Tauri 2 + Rust；主窗口（设置页）+ 系统托盘常驻；托盘菜单：打开设置 / 立即锁屏 / 熄屏 / 退出 | 启动后托盘图标常驻；点托盘"立即锁屏"与远程锁屏效果一致；退出需二次确认 |
| F-P0-02 | 内置 HTTP 服务 | axum；默认监听 `0.0.0.0:8326`，可在设置中修改；端口被占用时在 8326~8335 内自动重试 | 启动后 3 秒内可访问；占用时自动换端口并在设置窗提示实际端口；修改端口后重启生效 |
| F-P0-03 | 控制台静态页内置 | `/` 与 `/console` 均返回控制台单页应用；资源全部本地打包 | 断外网环境下手机仍能完整加载并使用（无任何对外请求） |
| F-P0-04 | 首次启动配对 | 首次启动生成 token + 8 位配对码 + 二维码；支持"重新生成"；token/配置持久化到本地配置文件 | 见 US-01 全部验收项；重启被控端后 token 保持不变 |
| F-P0-05 | Bearer token 鉴权 | 除 `/healthz`、`/pair` 外全部接口需鉴权；无/错 token 返回 401；同 IP 鉴权失败限速（10 次/分钟） | 用错误 token 调用任意控制接口返回 401 与错误码 40102；超限返回 429 |
| F-P0-06 | 远程锁屏 | 全屏置顶锁定窗口 + 系统锁（开关默认开）；锁定期间阻止 Alt+F4/Win 键等常见逃逸 | 见 US-02 全部验收项；锁定期尝试 Alt+F4、Ctrl+Alt+Del 之外的系统快捷键无法关闭窗口 |
| F-P0-07 | 锁屏三模式 | clock（时间+日期星期）/ image（自定义图片）/ black（纯黑） | 见 US-05；三模式切换无需重启应用 |
| F-P0-08 | 锁屏信息显示 | 时钟模式显示 HH:mm（24h，可配 12h）、下方小一号显示日期+星期；数字等宽对齐 | 时间与系统时间一致（每秒刷新不跳变）；日期星期与系统语言区域一致 |
| F-P0-09 | 本地解锁 | 密钥输入浮层 + 可配置快捷键（默认 Ctrl+Alt+Q）；防误操作；5 次错误冻结 30 秒 | 见 US-09 全部验收项；密钥以哈希存储，配置文件中不可见明文 |
| F-P0-10 | 远程解锁 | 关闭锁定窗口并点亮显示器；幂等；系统锁边界文案说明 | 见 US-03 全部验收项 |

## 6. 非功能需求

### 6.1 安全

| # | 需求 | 验收标准 |
| --- | --- | --- |
| S-01 | token 为 32 字节 CSPRNG 随机串；日志/接口响应均不回显完整 token | 任意日志与响应中 token 最多出现前 4 位 |
| S-02 | 鉴权失败限速：同 IP 10 次/分钟；配对码 5 次失败锁 5 分钟 | 超限返回 429 与剩余等待秒数 |
| S-03 | 配对码 10 分钟有效、一次性（换取 token 后作废） | 过期/已用配对码返回 401，页面引导重新生成 |
| S-04 | 仅局域网使用：文档明示"HTTP 明文，请勿在不受信网络使用"；CORS 默认关闭（控制台同源部署） | 非同源跨域请求被拒绝；README 有醒目安全说明 |
| S-05 | 本地解锁密钥哈希存储（如 argon2/bcrypt）；配置文件权限仅当前用户可读（Windows ACL / chmod 600） | 配置文件泄露也无法反推密钥 |
| S-06 | 图片上传：白名单后缀 + 魔数校验 + 服务端生成存储文件名 + 单文件 ≤10MB + 总量 ≤50MB | 恶意文件名（含 `../`）被安全重命名；超限拒绝 |
| S-07 | `/healthz` 仅返回版本号，不暴露主机名/路径等敏感信息 | 响应体仅含 `{"version":"x.y.z"}` |
| S-08 | 锁定窗口阻止常见逃逸：Alt+F4、Win 键、任务栏呼出（系统级 Ctrl+Alt+Del 无法也不应阻止） | 逐一验证无法经窗口关闭/切换逃逸 |
| S-09 | 已知风险披露：局域网明文 HTTP 可被同网段嗅探 token（一期接受，P2 以 HTTPS 解决）；文档与 README 均说明 | README 安全章节包含该风险与缓解建议 |

### 6.2 性能

| # | 需求 | 验收标准 |
| --- | --- | --- |
| P-01 | HTTP 接口（局域网）P95 < 100ms | 压测常见接口（/status、/lock）达标 |

## 8. 边界与风险

### 8.1 系统级安全边界（必须写进产品文案）

- **开启"系统锁"后，远程只能锁、不能解**：Windows `LockWorkStation` / macOS `CGSession` 进入的系统登录界面必须在本机输入密码。这是操作系统安全设计，本产品不做也不应做绕过。
- 产品侧的处理：设置中"系统锁"默认开启但可关闭；控制台"解锁"按钮下方常驻一行说明"若已启用系统级锁，解锁后将显示系统登录界面"；PRD/README/控制台三处口径一致。

### 8.2 安卓端定位说明（系统限制，文案必备）

- 安卓系统不允许第三方应用替换系统锁屏（Keyguard/SystemUI 由系统进程持有，普通应用最多展示自己的锁屏 Activity 但无法拦截系统返回 Home 与通知栏，且各类"锁屏 App"实际是悬浮窗方案，体验与安全性都不达标）。
- 因此：**一期安卓端 = 手机网页/PWA 控制端**（来源：已定技术方向），即"用安卓手机控制电脑"，而非"锁安卓手机的屏"。
- 二期可选的 Tauri 2 Android APK 仅是控制台的原生壳（设备管理、快捷入口），同样不提供安卓被控能力。

### 8.3 风险表

| 风险 | 可能性 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| Windows 上阻止 Win 键/任务栏逃逸不彻底 | 中 | 中 | 以全屏置顶 + 前台锁定 + 系统锁叠加兜底；验收逐项测试（F-P0-06） |
| 熄屏后系统进入休眠导致失联 | 中 | 高 | 熄屏期间显式保持执行状态阻止挂起（F-P0-11）；文档建议电源计划"永不睡眠" |
| 局域网明文 token 被嗅探 | 低 | 高 | 一期文档披露风险；P2 HTTPS（S-09） |
| 企业环境杀软/组策略拦截（端口监听、SC_MONITORPOWER） | 中 | 中 | 503 可读错误 + 日志诊断（F-P1-07）；README 提供放行指引 |
| 浏览器自动省电限制后台轮询 | 低 | 低 | 页面可见时轮询、隐藏时降频至 15s；操作后立即手动刷新一次状态 |
| Tauri 2 macOS 签名/公证门槛 | 中 | 中 | P1 阶段提供未签名包 + 安装引导；签名后视 donations/需求决定 |
